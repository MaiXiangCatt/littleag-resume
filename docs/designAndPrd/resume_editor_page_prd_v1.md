## 1. 背景与目标

简历编辑器是 LittleAgResume 的核心工作区。用户从控制台创建或打开一份简历后，在同一页面内管理内容结构、填写信息、调整版式、实时检查成品并导出无水印 PDF。

本期只验收桌面编辑器，页面路由为 `/resumes/:resumeId/edit`，仅登录用户可访问。

### 1.1 产品目标

- 用户可以在十分钟内完成一份可投递简历。
- 简历结构不受固定板块限制，用户可移除、恢复、排序、重命名和新增板块。
- 编辑结果自动保存，保存状态明确，异常和冲突可恢复。
- 预览与 PDF 使用同一份内容和模板，导出结果无水印。
- 同一份结构化内容可切换模板和排版，不改写原始内容。
- JSON 可完整迁移简历内容、样式、模板和头像。

### 1.2 非目标

- 移动端和平板端编辑。
- 离线编辑与多人协作。
- AI 优化、WYSIWYG 富文本和完整 GFM。
- 自由字段设计器、模板管理后台和头像库。

## 2. 核心用户故事

> 作为正在求职的用户，我希望自由组织简历板块并实时看到最终成品，在无需反复手动保存的情况下完成多版本简历，最终导出可直接投递的 PDF 或可迁移的 JSON。

---

## 3. 编辑工作台

页面由四部分组成：

1. 顶部工具栏：返回控制台、编辑简历标题、查看保存状态、切换草稿/已完成、JSON 导入导出、立即保存、导出 PDF、账号菜单。
2. 结构管理区：展示基本信息和有序板块，提供选择、排序、重命名、移除、恢复和新增入口。
3. 当前板块编辑区：一次只编辑当前选中的基本信息或内容板块。
4. A4 成品预览区：按当前模板、排版和内容展示最终结果，支持多页查看和缩放。

排版设置通过独立面板打开，不长期占用结构列表空间。

### 3.1 页面状态

- 加载中：显示编辑器骨架，禁止编辑和导出。
- 加载失败：说明失败原因并提供重试和返回控制台。
- 正常编辑：内容、结构、模板和排版均可修改。
- 保存中 / 已保存 / 保存失败：顶部持续展示当前状态；失败时可重试。
- 版本冲突：暂停自动保存，允许加载服务器版本或确认用本地版本覆盖。
- 导出中：导出按钮进入处理中状态，避免重复触发。
- 导入确认：展示文件标题、模板、板块和头像摘要，确认后才覆盖当前简历。

## 4. 基本信息

基本信息固定在简历头部，不参与排序、移除或恢复。

### 4.1 字段

- 姓名。
- 目标岗位。
- 手机号。
- 邮箱。
- 所在城市。
- 头像。
- 联系链接列表，每条包含名称和 URL，可用于个人网站、作品集、GitHub、LinkedIn 等。

### 4.2 头像行为

- 每份简历独立维护头像。
- 用户选择图片后按一寸照常用的 5:7 比例裁剪为 500×700 JPEG，确认后替换当前头像。
- 用户可以删除头像；没有头像时模板自动调整布局，不保留空图片位。
- 复制简历时保留头像；导入 JSON 时恢复头像。

### 4.3 成品样式

- 除姓名外，目标岗位、手机号、邮箱、城市和联系链接统一使用正文字号与正常黑色。
- 基本信息跟随模板与姓名保持相同的左对齐或居中方式。

## 5. 板块结构管理

### 5.1 内置板块

| 板块     | 默认状态 | 内容结构             |
| -------- | -------- | -------------------- |
| 个人简介 | 启用     | 一段多行文本         |
| 工作经历 | 启用     | 多条工作经历         |
| 教育背景 | 启用     | 多条教育经历         |
| 项目经历 | 启用     | 多条项目经历         |
| 技能     | 启用     | 板块级 Markdown 内容 |
| 奖项荣誉 | 未启用   | 多条奖项记录         |

每种内置板块只存在一个实例。除基本信息外，内置板块均可：

- 修改展示标题并恢复默认标题。
- 通过拖拽或上移/下移调整顺序。
- 从当前简历结构中移除。
- 从“添加板块”入口恢复；恢复时保留原内容。

### 5.2 自定义板块

- 用户输入板块名后创建自定义板块，并自动进入该板块的第一条空白记录。
- 用户可创建多个自定义板块，名称不要求唯一。
- 自定义板块与内置板块一起排序。
- 自定义板块的每条记录包含：标题、副标题、地点、开始时间、结束时间、“至今”状态和描述。
- 删除含有内容的自定义板块或记录前二次确认；确认后不可恢复。

### 5.3 板块切换与排序

- 点击结构项后，中间区域只展示当前板块的表单。
- 当前板块有明确选中态。
- 鼠标用户可拖拽排序；键盘和精确操作使用上移/下移。
- 基本信息始终位于结构列表首位。
- 当前板块被移除后，自动选择相邻可用板块。

## 6. 各板块字段

### 6.1 个人简介

- 支持简历安全 Markdown 的多行文本。
- 空内容不进入成品预览。

### 6.2 工作经历

- 公司、岗位、地点、开始时间、结束时间、至今状态、工作描述。
- 成品中公司、岗位和地点按此顺序同行展示，使用一致的颜色和字号；日期在同行右侧展示。

### 6.3 教育背景

- 学校、专业、学历、开始时间、结束时间、教育描述。

### 6.4 项目经历

- 项目名称、项目角色、开始时间、结束时间、至今状态、项目描述。

### 6.5 技能

- 使用板块级 Markdown 描述自由填写技能、工具和熟练程度。
- 不提供结构化技能标签或熟练度选择，成品按普通 Markdown 正文渲染。

### 6.6 奖项荣誉

- 奖项名称、颁发方、获得时间、描述。

### 6.7 描述规则

- 工作、教育、项目、奖项和自定义板块的固定字段合并为同一条标题行，使用条目标题字号与正常黑色；日期在同行右侧展示。
- 个人简介、技能及工作、教育、项目、奖项和自定义板块的描述支持 Markdown 输入。
- 支持段落、单次换行、有序/无序列表、粗体、斜体、行内代码和安全链接。
- HTML 只作为文本显示；标题、图片、表格和代码块不渲染为对应格式。
- 固定字段仍使用纯文本输入。

## 7. 模板与排版

### 7.1 首发模板

- 现代编辑：强调清晰层级、留白和品牌强调色。
- 经典专业：强调稳重、紧凑信息组织和传统简历阅读顺序。

模板切换只改变呈现，不改变字段、板块内容或排序。

### 7.2 排版选项

- 字号：姓名、板块标题、条目标题和正文分别使用全局数值控制。
- 行距：使用 `1–2.5` 的数值倍数。
- 页边距：上、右、下、左分别使用像素数值控制。
- 板块间距：使用像素数值控制。
- 字体：支持思源黑体和思源宋体，网页预览与 PDF 使用同一字体。
- 主题色：提供梅紫、藏蓝、青绿、铁锈、炭灰、纯黑预设，并支持调色盘自定义六位十六进制颜色。
- 重置排版：恢复当前模板的默认设置。

## 8. 实时预览与 PDF

- 预览以 A4 多页成品展示，并支持缩放。
- 内容、板块顺序、模板和排版变更会自动更新预览。
- 空字段、空记录和已移除板块不进入纸面，不展示示例占位文字。
- 导出使用当前本地内容；导出前尝试保存，保存失败时提示但允许继续。
- 必填信息不完整时展示缺失项提醒，用户确认后仍可导出。
- PDF 无平台水印，文件名使用简历标题。
- PDF 开始下载后记录一次成功导出；生成失败不计数。

---

## 9. 保存、完成态与冲突

- 用户停止输入后自动保存；板块增删排序、模板和排版等关键操作更快触发保存。
- 所有保存按顺序提交，较早响应不能覆盖较新的本地内容。
- 用户可以点击“立即保存”刷新当前待保存内容。
- 保存失败时保留本地编辑结果，并允许重试。
- 离开页面时，仅在仍有未保存内容或保存失败时提示。
- 多个页面同时编辑同一份简历产生版本冲突时，不静默覆盖。
- 草稿允许不完整内容。
- 用户选择“标记为已完成”时校验姓名、目标岗位以及已启用板块中的有效记录；未通过时定位并说明问题。
- 用户可以把已完成简历重新设为草稿继续编辑。

---

## 10. JSON 导入导出

- JSON 导出为单文件，包含版本、标题、模板、结构化内容、排版和压缩头像。
- 编辑器导入只接受合法的 LittleAgResume v2 文件，不兼容 v1。
- 校验失败时不修改当前简历，并说明错误。
- 校验成功后展示摘要；用户确认后覆盖当前简历。
- 控制台导入继续创建一份新的草稿简历。
