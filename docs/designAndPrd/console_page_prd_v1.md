## 1. 背景与目标

### 1.1 背景

Console 是用户登录后的主工作台，对应路由 `/console`。用户在这里集中管理自己的全部简历——查看、创建、编辑、导出、删除、导入，以及了解简历的整体状态。它是用户登录后使用频率最高的页面，承担"简历资产管理中心"的角色。

### 1.2 页面目标

| 目标 | 说明 |
|------|------|
| 一目了然的简历总览 | 用户进入即可看到自己所有简历及关键状态 |
| 高效的简历管理 | 创建、编辑、导出、删除、导入等操作均在 3 次点击内可达 |
| 清晰的状态感知 | 通过统计数据和状态标签，用户能快速掌握简历进度 |
| 快速定位 | 支持搜索、筛选、分页，简历数量增多时仍可快速找到目标 |

### 1.3 进入条件

- 仅登录用户可访问；未登录用户访问 `/console` 时跳转回首页 `/`
- 用户从首页「立即开始」注册/登录成功后自动跳转至此

## 3. 区域 1 — 顶部导航栏

### 3.1 内容组成（左 → 右）

| 元素 | 说明 |
|------|------|
| Logo | LittleAgResume 品牌标识，点击返回控制台首页 |
| 搜索框 | 居中，占位文字"搜索简历"，右侧展示快捷键提示（⌘K） |
| 帮助入口 | 问号图标，点击打开帮助/使用说明 |
| 通知入口 | 铃铛图标，展示系统通知（MVP 阶段可为静态入口） |
| 用户菜单 | 用户头像 + 昵称 + 下拉箭头，点击展开下拉菜单 |

### 3.2 搜索框需求

- 支持按简历名称进行实时搜索/过滤
- 支持快捷键（⌘K / Ctrl+K）快速聚焦到搜索框
- 搜索结果实时反映在下方简历卡片区
- 搜索无结果时展示空状态提示（如"没有找到相关简历"）

### 3.3 用户菜单需求

- 展示当前登录用户头像与昵称
- 点击展开下拉菜单，至少包含：
  - 账号设置（MVP 可占位）
  - 退出登录（清除登录态，返回首页）

## 4. 区域 2 — 页面标题区

### 4.1 内容

| 元素 | 文案 |
|------|------|
| 主标题 | 我的简历 |
| 副标题 | 管理你的简历文档，随时编辑与导出 |

### 4.2 「导入已有简历」按钮需求

- 主按钮样式（品牌色），位于标题区右侧

- 导入成功后：新简历出现在卡片列表中，并给出成功提示
- 导入失败（格式错误/数据不合法）时：给出明确的错误提示，说明失败原因
- 导入过程中展示加载状态

## 5. 区域 3 — 数据统计栏

### 5.1 统计指标

横向展示 4 项关键指标，每项含图标、数值、单位与名称：

| 指标 | 示例值 | 说明 |
|------|--------|------|
| 总简历数 | 6 份 | 用户当前拥有的简历总数 |
| 草稿 | 2 份 | 处于草稿状态、尚未完成的简历数 |
| 已完成 | 4 份 | 已标记为完成状态的简历数 |
| 已导出 | 12 次 | 用户累计导出简历的次数 |

### 5.2 需求说明

- 数值需实时反映用户当前真实数据，随简历的增删改而动态更新
- 各统计项与筛选标签的口径需保持一致（如"草稿""已完成"数量应与筛选后的卡片数一致）

## 6. 区域 4 — 筛选与视图切换栏

### 6.1 状态筛选标签页

横向标签页，用于按状态快速过滤简历：

| 标签 | 过滤范围 |
|------|---------|
| 全部 | 展示所有简历（默认选中） |
| 最近编辑 | 按最近编辑时间排序展示 |
| 已完成 | 仅展示已完成状态的简历 |
| 草稿 | 仅展示草稿状态的简历 |

### 6.2 筛选下拉

- 位于标签页右侧，文案"筛选"
- 点击展开更多筛选/排序条件（如按创建时间、按名称排序等，具体项待产品确认，见待定事项）

### 6.3 需求说明

- 切换标签后，下方卡片区实时更新，且与分页联动（切换筛选后重置到第 1 页）
- 当前选中标签需有明显的选中态样式
- 筛选条件与搜索框可叠加生效

## 7. 区域 5 — 简历卡片网格

### 7.1 布局

- 卡片以网格形式排列，多列展示
- 第一个位置固定为「创建新简历」卡片，其后为用户的简历卡片列表

### 7.2 「创建新简历」卡片

| 元素 | 说明 |
|------|------|
| 视觉样式 | 与普通简历卡片区分（虚线边框 + 品牌色调），中心为大号「+」图标 |
| 主文案 | 创建新简历 |
| 辅助文案 | 从空白模板开始，快速创建你的专属简历 |
| 点击行为 | 进入简历编辑页，创建一份新的空白简历 |

### 7.3 简历卡片

每张简历卡片包含以下元素：

| 元素 | 说明 |
|------|------|
| 缩略图预览 | 卡片内展示简历内容的缩略预览图 |
| 头像 | 简历对应的个人头像 |
| 姓名 | 简历中的姓名 |
| 简历标题 | 如"产品经理简历""市场营销简历"等 |
| 状态标签 | 展示当前状态：已完成 / 草稿（不同状态用不同颜色区分） |
| 最近编辑时间 | 如"最近编辑：2 小时前" |
| 导出 PDF 按钮 | 主操作，点击将简历导出为 PDF 文件 |
| 更多操作入口 | 「...」图标，展开更多操作 |
| 编辑操作 | 点击进入该简历的编辑页 |
| 删除操作 | 点击删除该简历（需二次确认） |

### 7.4 卡片操作需求

**编辑**

- 点击卡片主体或「编辑」进入该简历的编辑页

**导出 PDF**

- 点击「导出 PDF」将当前简历导出为 PDF 文件并下载
- 导出过程中展示加载状态
- 导出成功后「已导出」统计次数 +1
- 导出失败时给出明确错误提示

**删除**

- 点击「删除」弹出二次确认弹窗，提示"删除后不可恢复"
- 用户确认后删除该简历，卡片从列表移除，相关统计数据同步更新
- 取消则不做任何操作

**更多操作（「...」）**

- 可包含：复制简历、重命名等（具体项待产品确认，见待定事项）

### 7.5 空状态

- 当用户没有任何简历时：卡片区仅展示「创建新简历」卡片，并可辅以引导文案鼓励用户创建第一份简历
- 当搜索/筛选结果为空时：展示"没有找到符合条件的简历"提示

## 8. 区域 6 — 分页栏

### 8.1 需求

- 当简历数量超过单页展示上限时，展示分页控件
- 支持页码切换（上一页 / 下一页 / 具体页码跳转）
- 提供每页展示数量选择（如每页 8 份，示意图默认值为 8）
- 切换页码或每页数量后，卡片区更新且滚动位置回到卡片区顶部
- 分页需与搜索、筛选联动（在筛选结果范围内分页）

## 9. 核心用户流程

### 9.1 创建新简历

```
进入 Console → 点击「创建新简历」卡片 → 进入编辑页（空白简历）
```

### 9.2 编辑已有简历

```
进入 Console → 定位目标简历（搜索/筛选/浏览）→ 点击卡片或「编辑」→ 进入编辑页
```

### 9.3 导出简历

```
定位目标简历 → 点击卡片上的「导出 PDF」→ 生成并下载 PDF → 「已导出」统计 +1
```

### 9.4 删除简历

```
定位目标简历 → 点击「删除」→ 二次确认弹窗 → 确认 → 卡片移除、统计更新
```

### 9.5 导入简历

```
点击「导入已有简历」→ 选择简历数据文件 → 校验 → 成功后新增卡片 / 失败给出提示
```

## 10. 非功能性需求

| 类别 | 需求 |
|------|------|
| 响应式 | 需适配桌面与移动端；小屏幕下卡片网格自动调整列数，各操作按钮可正常点击 |
| 加载状态 | 简历列表加载、导入、导出等异步操作均需展示加载/进度状态 |
| 反馈提示 | 所有关键操作（创建、导入、导出、删除）成功或失败均需明确的用户反馈 |
| 数据一致性 | 统计栏、筛选标签、卡片列表的数据口径需保持一致并实时同步 |
| 权限 | 用户仅能查看和操作属于自己的简历 |

## 13. 开发前确认结论（2026-07-21）

- 本期实现 Console 的真实 Resume 数据模型与管理 API，但不定义 `contentJson` 内部的简历内容 Schema；内容暂按不透明 JSONB 存储。
- Resume 状态使用 `draft` / `completed`。新建、导入和复制均生成草稿；完成状态后续由编辑器显式切换，不根据字段完整度自动推断。
- 本期不实现简历版本历史；用户需要保留分支时使用“复制简历”。
- 卡片中的姓名、头像和真实缩略图依赖编辑器内容模型，本期使用通用占位预览，不解析 `contentJson`。
- JSON 导入仅接受 LittleAgResume v1 外层格式 `{ version, title, content }`，成功后创建一份新的草稿简历；`content` 内部结构本期不校验。
- 状态标签页调整为“全部 / 已完成 / 草稿”；原“最近编辑”能力并入排序。排序项为最近更新、最早更新、最新创建、名称升序。
- 单账号简历总数暂不限制。列表采用服务端搜索、状态过滤、排序与分页，默认每页 6 份，可选 6 / 12 / 24。
- 更多操作包含复制和重命名；分享不在 MVP 范围内。
- PDF 导出按钮与导出统计保留，但本期按钮禁用并提示编辑器完成后开放。后续每次成功生成并开始下载计数一次，失败不计数。
- 帮助、通知和账号设置本期保留入口，点击后提示功能暂未开放；退出登录保持真实可用。
- 编辑器路由统一为 `/resumes/:resumeId/edit`。本期只提供占位页面和返回 Console 的入口。
- 桌面端以 `docs/UIdesign/consolePage.png` 为视觉基准；平板改为双列、移动端改为单列并重排导航与筛选区域。
