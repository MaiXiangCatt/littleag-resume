# LittleAgResume 法律文本使用说明

> 文档状态：上线前草案  
> 起草日期：2026 年 7 月 30 日  
> 适用场景：中国大陆自然人使用、个人运营、免费非商业化、服务器位于新加坡

本目录包含：

- `privacy-policy.zh-CN.md`：隐私政策；
- `terms-and-content-rules.zh-CN.md`：用户服务协议及内容规则；
- `cross-border-processing-notice.zh-CN.md`：个人信息跨境处理说明及单独同意文本。

这些文本根据当前代码和部署方式起草，不是可以不经核对直接发布的通用模板。正式上线前必须完成下列事项；未完成的内容在正文中以 `[待填写]`、`[待确认]` 或“上线前确认”标记。

## 一、必须补齐的运营信息

1. 运营者真实姓名。运营主体是自然人时，不宜只填写网名或 GitHub 用户名。
2. 专门用于处理隐私、账号注销、内容投诉和安全事件的联系邮箱：`littleag_resume@163.com`。
3. 能够接收法律文书或监管联系的常用联系地址（如决定公开）。
4. 腾讯云合同乙方为腾讯云计算（北京）有限责任公司，合同联系邮箱为 `cloud_hetong@tencent.com`；仍建议通过工单确认新加坡地域是否存在其他境外实际处理主体。
5. Cloudflare 代理已经启用。
6. Resend 发信区域为日本东京。Resend 的打开和点击追踪默认关闭，当前服务端发送请求也未开启相关功能；仍应在 Resend 控制台的 Domains → Tracking 中确认两项保持关闭。

## 二、上线前必须补齐的产品能力

1. **注册前展示并记录同意**
   - 在发送注册邮箱验证码之前展示法律文本；
   - 勾选一：“我已阅读并同意《用户服务协议及内容规则》，并已阅读《隐私政策》”；
   - 勾选二：“我已阅读《个人信息跨境处理说明》，并单独同意将相关个人信息提供至境外处理”；
   - 两个勾选框均不得默认选中；
   - 后端应记录文本版本、同意时间、账号或邮箱、必要的请求标识，并验证同意状态，不能只依赖前端禁用按钮。

2. **个人信息权利入口**
   - 至少提供稳定可用的联系邮箱 `littleag_resume@163.com`；
   - 建议补充账号注销功能；
   - 支持用户请求查阅、复制、更正、删除、限制处理、撤回同意；
   - 撤回跨境同意后，应停止新的云端处理；如云端服务因此无法继续，应允许用户先导出数据。

3. **删除和留存机制**
   - 当前简历删除使用软删除，不能在政策中承诺“删除后立即物理清除”；
   - 上线前应增加软删除数据的定期清理机制；
   - 应确定账号注销后数据库、头像文件、备份的具体删除周期；
   - 本草案暂按“在线数据 30 日内删除或匿名化、备份最长 90 日轮换”设计，实际系统必须与文本一致。

4. **安全日志**
   - 网络安全日志原则上应依法留存不少于六个月；
   - 当前容器日志只按容量轮换，无法保证一定覆盖六个月；
   - 上线前应增加独立、受访问控制的安全日志留存方案，并避免把简历正文、密码、验证码、访问令牌写入日志。

5. **敏感个人信息**
   - 简历自由文本可能被用户写入身份证号、宗教信仰、健康情况、精确住址等敏感信息；
   - 应在编辑器明确提示用户不要填写与求职无关的敏感信息；
   - 上传头像前建议进行单独提示和确认；
   - 如产品未来主动要求用户填写敏感个人信息，需要重新评估必要性并取得单独同意，不能只依赖注册时的概括同意。

6. **未成年人**
   - 当前没有监护人同意流程；
   - 本草案将账号服务限定为年满 18 周岁用户；
   - 如果未来希望向未成年人开放，需另行设计监护人同意和未成年人专门个人信息处理规则。

7. **跨境影响评估和服务商约束**
   - 在正式收集前形成书面的个人信息保护影响评估记录；
   - 核对腾讯云、Resend、Cloudflare 的服务条款、数据处理条款和实际处理地点；
   - 保存委托处理或跨境提供相关合同、配置截图、数据流说明和定期检查记录；
   - 每年统计自 1 月 1 日起累计向境外提供的个人信息主体数量及敏感个人信息情况，确认是否仍满足数据出境手续豁免条件。

## 三、推荐的注册页文案

```text
[ ] 我已阅读并同意《用户服务协议及内容规则》，并已阅读《隐私政策》

[ ] 我已阅读《个人信息跨境处理说明》，知悉账号信息、简历内容、
    头像及必要的访问记录将在新加坡等境外地点处理，并单独同意
    该等跨境处理
```

《用户服务协议及内容规则》《隐私政策》《个人信息跨境处理说明》应分别可点击、可完整阅读。第二项应保持独立，不要合并成“我同意所有协议”。

由于点击“发送验证码”时邮箱地址已经会被传给新加坡服务器并交由 Resend 处理，勾选校验必须位于发送验证码动作之前。
